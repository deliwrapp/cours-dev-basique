Module 3

DevTools : méthode de diagnostic

  1. Inspecter l’élément
  2. Vérifier que la règle CSS est chargée
  3. Tester une valeur dans le navigateur
  4. Identifier une surcharge éventuelle
  5. Reporter la correction dans le fichier
